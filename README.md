# NataPrep

NataPrep is an AI-powered platform designed to help students prepare for the National Aptitude Test in Architecture (NATA). It offers interactive practice tests, real-time drawing feedback, and personalized study resources to enhance learning outcomes.

## Features

- **AI-Powered Drawing Feedback**: Real-time feedback on architectural drawings using advanced AI algorithms.
- **Adaptive Learning Paths**: Personalized study plans tailored to individual learning styles and progress.
- **Community Section**: A vibrant community of 15,000+ students and 50+ mentors for collaboration and support.
- **3D Visualization**: Interactive 3D models and visualizations using Three.js to enhance understanding of architectural concepts.
- **AI Chatbots**: Intelligent chatbots to assist students with queries and provide instant support.

## Technologies Used

- **Frontend**: React.js, Three.js, Tailwind CSS
- **Backend**: Node.js, Express.js
- **Database**: Supabase
- **AI/ML**: Custom AI models for drawing feedback and chatbots
- **Deployment**: Vercel, Render

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/nataprep.git
   cd nataprep
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Set up environment variables:

   - Create a `.env` file in the root directory.
   - Add the following variables:
     ```
     VITE_SUPABASE_URL=your_supabase_url
     VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
     ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open your browser and navigate to `http://localhost:5173`.
